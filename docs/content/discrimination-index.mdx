# Every candidate set

One row per item. Open any of them to read the whole candidate set with its
grades — and a button to hide the grades, if you want to try the item yourself
before seeing the answer key.

The grades are the point of reading these. `3` and `2` mean a candidate answers
the question; `1` means it is on the same topic and does **not** answer it; `0`
means it is noise. See [the three categories](./tasks/search-result-discrimination/categories)
for where each grade came from and who decided it.
